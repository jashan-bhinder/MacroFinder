1. WHEN IT COMES TO COMMIT CONVENTIONS

type(scope): description
- feat for new features
- fix for bug fixes
- docs for documentation
- style for formatting only
- refactor for code changes without feature/fix
- test for tests
- chore for maintenance
- build for build system changes
- ci for CI/CD changes

examples:

- feat(auth): add password reset flow
- fix(api): handle 429 retry response
- docs(readme): clarify local setup steps
- refactor(ui): simplify modal state handling
- test(cart): add checkout edge case coverage
- chore(deps): bump eslint to 9.2.0
